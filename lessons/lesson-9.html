Week 9 of 10

Strings

Text is everywhere — names, messages, passwords, search boxes. In Java, a piece of text is a String, and it comes loaded with handy tools for measuring, searching, slicing, and transforming it. You'll also meet one of the most famous beginner traps in all of Java: comparing strings the wrong way.

Lecture: ~40 min
Exercise: ~15 min
Topics: length · charAt · substring · indexOf · equals · split · immutability
Part 1 — What a String Is

A String is a sequence of characters — letters, digits, spaces, punctuation — in order, like beads on a string. The word "Hello" is five characters in a row: H, e, l, l, o. You write a String literal inside double quotes.

Here's something important: a String is an object (remember Lesson 7?), not a simple type like int. That's why String is capitalized, and why it comes with methods you call with a dot — like .length(). You can create one the easy way (just quotes) and immediately start using its tools:

public class Main {
    public static void main(String[] args) {
        String greeting = "Hello";
        String name = "Mia";

        System.out.println(greeting);
        System.out.println("That word has " + greeting.length() + " characters.");
        System.out.println("Name length: " + name.length());
    }
}
💡 length() has parentheses

Watch the difference from arrays! An array used arr.length (no parentheses — it's a field). A String uses greeting.length() with parentheses, because it's a method call. Easy to mix up — Java will remind you if you forget.

Part 2 — Characters & Indexing

Just like arrays, the characters in a String have index numbers starting at 0. The first character is at index 0, the second at index 1, and so on. Use charAt(i) to grab the character at a position. For "Hello":

String: "Hello" Index: 0 1 2 3 4 Char: H e l l o "Hello".charAt(0) -> 'H' "Hello".charAt(4) -> 'o' "Hello".length() -> 5 (so the last index is length - 1 = 4)
public class Main {
    public static void main(String[] args) {
        String word = "Hello";

        System.out.println("First char: " + word.charAt(0));
        System.out.println("Third char: " + word.charAt(2));

        int last = word.length() - 1;
        System.out.println("Last char:  " + word.charAt(last));
    }
}
⚠️ Off the end = crash

Valid indexes go from 0 to length() - 1. Asking for "Hello".charAt(5) reaches past the end and throws a StringIndexOutOfBoundsException — the String cousin of the array out-of-bounds error from Lesson 4. The last real character is always at length() - 1.

Part 3 — The Everyday String Toolbox

Strings come with dozens of built-in methods. Here are the ones you'll reach for constantly. Each one answers a question or hands back a new string:

MethodWhat it doesExample on "Hello"
toUpperCase()All capitals"HELLO"
toLowerCase()All lowercase"hello"
indexOf("l")First position of text (or -1)2
contains("ell")Is the text inside? (true/false)true
substring(1, 4)Slice from index 1 up to (not incl.) 4"ell"
replace("l", "L")Swap every match"HeLLo"
public class Main {
    public static void main(String[] args) {
        String s = "Hello";

        System.out.println(s.toUpperCase());     // HELLO
        System.out.println(s.toLowerCase());     // hello
        System.out.println(s.indexOf("l"));      // 2  (first 'l')
        System.out.println(s.contains("ell"));   // true
        System.out.println(s.substring(1, 4));   // ell
        System.out.println(s.replace("l", "L")); // HeLLo
    }
}
💡 substring(start, end) stops just before end

substring(1, 4) gives you indexes 1, 2, and 3 — but not 4. The end number is "up to, but not including," exactly like the loop bounds you used with arrays. So the length of the slice is simply end - start (here, 4 - 1 = 3 characters).

trim() and split()

Two more workhorses: trim() removes blank space from the start and end (great for cleaning up typed input), and split() breaks a String into an array of pieces wherever it finds a separator:

public class Main {
    public static void main(String[] args) {
        String messy = "   hi there   ";
        System.out.println("[" + messy.trim() + "]");   // [hi there]

        String csv = "apple,banana,cherry";
        String[] fruits = csv.split(",");               // break on each comma
        System.out.println("Pieces: " + fruits.length);
        for (String f : fruits) {
            System.out.println(" - " + f);
        }
    }
}
Part 4 — Joining Strings (Concatenation)

Gluing strings together is called concatenation. You've already been doing it with the + operator. There's also a method, .concat(), but + is what almost everyone uses because it's shorter and can join strings with numbers too:

public class Main {
    public static void main(String[] args) {
        String first = "Ada";
        String last = "Lovelace";

        String full = first + " " + last;        // the + way (most common)
        System.out.println(full);

        String full2 = first.concat(" ").concat(last);   // the .concat() way
        System.out.println(full2);

        int age = 12;
        System.out.println(first + " is " + age + " years old.");  // + mixes in numbers
    }
}
⚠️ Numbers and + can surprise you

When + sees a String, it switches to "join text" mode. So "Score: " + 3 + 4 gives "Score: 34" (it glues "3" then "4"), not "Score: 7"! If you want the math first, wrap it in parentheses: "Score: " + (3 + 4) gives "Score: 7".

Part 5 — Comparing Strings: the #1 Beginner Trap

This is the most important section in the lesson. To check if two strings have the same text, you must use .equals() — never ==. Here's why: == asks "are these the exact same object in memory?", while .equals() asks "do these contain the same characters?" For text, you almost always mean the second one.

public class Main {
    public static void main(String[] args) {
        String a = "hello";
        String b = "hel" + someText();   // built at runtime -> a different object

        System.out.println("a == b is:        " + (a == b));        // false (!)
        System.out.println("a.equals(b) is:   " + a.equals(b));     // true  (correct)
    }

    static String someText() {
        return "lo";
    }
}
⚠️ Burn this into your memory

Use .equals() to compare String content. == on strings compares identity (same object?), and it sometimes looks like it works — then mysteriously fails when the strings are built in different ways, like above. This bug has tripped up basically every Java beginner ever. Text comparison = .equals(). Always.

equalsIgnoreCase() for "close enough"

Often you don't care about capitalization — "YES", "yes", and "Yes" should all count as a yes. equalsIgnoreCase() compares the text while ignoring upper/lower case:

public class Main {
    public static void main(String[] args) {
        String answer = "YES";

        System.out.println(answer.equals("yes"));            // false (case differs)
        System.out.println(answer.equalsIgnoreCase("yes"));  // true  (ignores case)

        if (answer.equalsIgnoreCase("yes")) {
            System.out.println("Great, let's go!");
        }
    }
}
Part 6 — Strings Are Immutable

Here's a surprising fact: once a String is created, it can never be changed. This is called being immutable ("un-changeable"). Methods like toUpperCase() don't edit the original — they build and return a brand-new String and leave the old one exactly as it was.

public class Main {
    public static void main(String[] args) {
        String s = "hello";

        s.toUpperCase();                  // makes "HELLO"... but we ignore it!
        System.out.println(s);            // still "hello" — unchanged

        s = s.toUpperCase();              // to keep it, save it back
        System.out.println(s);            // now "HELLO"
    }
}
💡 The fix: catch the new string

Because a String can't change itself, calling s.toUpperCase() alone is pointless — the result floats away. You have to assign it back: s = s.toUpperCase();. Think of it like math: x + 1 doesn't change x unless you write x = x + 1. Same idea.

Part 7 — Looping Over the Characters

Combine length() and charAt() with a loop (Lesson 3) and you can walk through a String one character at a time — counting things, searching, transforming. Here we count how many times the letter 'l' appears:

public class Main {
    public static void main(String[] args) {
        String word = "yellow umbrella";
        int count = 0;

        for (int i = 0; i < word.length(); i++) {
            char c = word.charAt(i);
            if (c == 'l') {
                count++;
            }
        }

        System.out.println("'l' appears " + count + " times.");
    }
}
💡 char uses single quotes

One character on its own is a char, written with single quotes: 'l'. A String — even a one-letter one — uses double quotes: "l". Since char is a simple type (not an object), comparing two chars with == is perfectly fine — the .equals() rule is only for String objects.

⌨️ Coding Challenge ⏱ ~15 min

Task 1 — Initials
Given String first = "Ada"; and String last = "Lovelace";, print the person's initials with dots, like A.L. — using charAt(0) on each name.

Hint: charAt(0) gives a char; you can join chars and strings with +.

Build the result with concatenation: String initials = first.charAt(0) + "." + last.charAt(0) + "."; then System.out.println(initials);. The + turns each char into text as it joins.

Task 2 — Password check (use equals!)
Set String entered = "Swordfish"; and String correct = "swordfish";. Use equalsIgnoreCase() to check if they match, and print "Access granted" or "Denied". Then try it with plain equals() and notice the difference.

if (entered.equalsIgnoreCase(correct)) { System.out.println("Access granted"); } else { System.out.println("Denied"); }. With equalsIgnoreCase the capital S doesn't matter, so it's granted. With equals it would be denied — never use == here!

Task 3 — Count the vowels
Loop over String text = "programming"; and count how many vowels (a, e, i, o, u) it contains, then print the total. (For "programming" the answer is 3.)

Loop with for (int i = 0; i < text.length(); i++), grab char c = text.charAt(i);, and test it: if (c == 'a' || c == 'e' || c == 'i' || c == 'o' || c == 'u') count++;. Print count after the loop.

Arrays

One variable can hold one value — but what if you have 30 test scores? Arrays let you store a whole list of values under a single name, then loop through them. Learn to create, index, iterate, and spot the classic off-by-one trap.

Lecture: ~40 min
Exercise: ~15 min
Topics: create · index · .length · iterate · patterns · 2D
Part 1 — Creating Arrays

Think of an array as a row of numbered lockers, all the same type, sitting next to each other. Each locker holds one value, and every locker has a number — its index — so you can find it again. Instead of score1, score2, score3… you make one array and use its index.

Making an Empty Array with new

One way is to ask for a fixed number of empty slots using new. Java fills a fresh number array with 0s automatically, ready for you to fill in:

int[] scores = new int[4];   // room for 4 ints, all start at 0

System.out.println("Length: " + scores.length);
System.out.println("Before: " + scores[0] + " " + scores[1] + " " + scores[2] + " " + scores[3]);

scores[0] = 90;
scores[1] = 85;
System.out.println("After:  " + scores[0] + " " + scores[1] + " " + scores[2] + " " + scores[3]);

Array Literals — values right away

If you already know the values, list them inside { } and Java counts them for you — no need to say how many. Arrays can hold any single type: int, double, String, and more.

int[] ages = {12, 13, 11, 14};
String[] names = {"Mia", "Leo", "Ava"};

System.out.println("There are " + ages.length + " ages");
System.out.println("First name: " + names[0]);
System.out.println("Last name: " + names[names.length - 1]);
💡 One type per array

An array holds values of one type only — an int[] can't hold text, and a String[] can't hold numbers. Its size is also fixed once created: an array of 4 always has exactly 4 slots. (Need a list that grows? That's ArrayList, coming in Lesson 10.)

Part 2 — Indexing & .length

Here's the rule that trips up everyone at first: indexes start at 0, not 1. The first element is at index 0, the second at 1, and so on. So in an array of 5 items, the valid indexes are 0, 1, 2, 3, 4 — the last index is always length - 1.

Index →01234
Value1020304050

Every array knows its own size through .length (notice: no parentheses — it's not a method). Use it to always find the last element safely:

int[] nums = {10, 20, 30, 40, 50};

System.out.println("Length is " + nums.length);
System.out.println("First element (index 0): " + nums[0]);
System.out.println("Third element (index 2): " + nums[2]);

int lastIndex = nums.length - 1;   // last index is length - 1, never length
System.out.println("Last element (index " + lastIndex + "): " + nums[lastIndex]);
⚠️ Off-by-one & out-of-bounds

An array of length 5 has no index 5 — the slots are 0 to 4. Asking for nums[5] crashes with ArrayIndexOutOfBoundsException. The fix is the same golden rule you saw with loops: stop at i < length, never i <= length.

Part 3 — Reading & Writing Elements

You use the same array[index] syntax for both jobs: on the right of an = it reads the value; on the left it writes (overwrites) it. Swapping two elements needs a temporary holder so you don't lose a value.

int[] box = {1, 2, 3};

box[1] = 99;          // write: overwrite the value at index 1
System.out.println("After change: " + box[0] + " " + box[1] + " " + box[2]);

// Swap the first and last using a temporary holder
int temp = box[0];
box[0] = box[2];
box[2] = temp;
System.out.println("After swap:   " + box[0] + " " + box[1] + " " + box[2]);
💡 Why the temp variable?

If you wrote box[0] = box[2] then box[2] = box[0], you'd lose the original first value — it got overwritten in step one, so both slots end up the same. The temp holder remembers it just long enough to finish the trade.

Part 4 — Iterating Over Arrays

The real power of arrays shows up when you pair them with a loop — now one chunk of code can handle 4 items or 4,000. There are two common ways.

Classic for — when you need the index

Counting from 0 up to length - 1 visits every element and gives you the index i to use:

int[] temps = {18, 21, 25, 19};

for (int i = 0; i < temps.length; i++) {
    System.out.println("Day " + (i + 1) + ": " + temps[i] + "°C");
}

for-each — when you just want the values

If you don't care about positions, the for-each loop is shorter and safer (no index to get wrong):

String[] fruits = {"apple", "banana", "cherry"};

for (String fruit : fruits) {
    System.out.println("I like " + fruit);
}
Part 5 — Common Array Patterns

A handful of patterns come up again and again. Learn these four and you'll recognise them everywhere.

Sum & Average

Keep a running sum that starts at 0, add each element, then divide by length for the average. Cast to double so you don't lose the decimals:

int[] marks = {70, 85, 90, 60, 95};

int sum = 0;
for (int mark : marks) {
    sum += mark;
}
double average = (double) sum / marks.length;

System.out.println("Sum: " + sum);
System.out.println("Average: " + average);

Max & Min

Start by assuming the first element is both the biggest and smallest, then let the loop correct you whenever it finds something better:

int[] data = {42, 17, 89, 5, 63};

int max = data[0];   // assume the first is the biggest...
int min = data[0];   // ...and the smallest, for now
for (int n : data) {
    if (n > max) {
        max = n;
    }
    if (n < min) {
        min = n;
    }
}
System.out.println("Largest:  " + max);
System.out.println("Smallest: " + min);

Search & Count

To search, walk the array and remember the index where you found your target (start at -1 to mean "not found"). To count, keep a tally and bump it up whenever an element matches a rule:

int[] values = {4, 8, 15, 16, 23, 42};
int target = 15;

int foundAt = -1;        // -1 means "not found yet"
int evenCount = 0;
for (int i = 0; i < values.length; i++) {
    if (values[i] == target) {
        foundAt = i;
    }
    if (values[i] % 2 == 0) {
        evenCount++;
    }
}
System.out.println("Found " + target + " at index " + foundAt);
System.out.println("Even numbers: " + evenCount);

Part 6 — A Peek at 2D Arrays

Sometimes a single row isn't enough — think of a chessboard, a spreadsheet, or a game map. A 2D array is an "array of arrays": a grid with rows and columns. You use two indexes — grid[row][col] — and two nested loops to walk it.

int[][] grid = {
    {1, 2, 3},
    {4, 5, 6}
};

System.out.println("Rows: " + grid.length);           // 2 rows
System.out.println("Columns: " + grid[0].length);     // 3 columns
System.out.println("Middle of row 1: " + grid[1][1]); // the value 5

// Walk the whole grid: outer loop = rows, inner loop = columns
for (int row = 0; row < grid.length; row++) {
    for (int col = 0; col < grid[row].length; col++) {
        System.out.print(grid[row][col] + " ");
    }
    System.out.println();   // new line after each row
}
💡 Read it as [row][column]

The first index picks the row, the second picks the column within that row — always in that order. grid[1][1] means "row 1, column 1." 2D arrays power grids, tic-tac-toe boards, images (rows of pixels), and much more.

Task 1 — Print It Backwards
Given int[] nums = {1, 2, 3, 4, 5};, use a loop to print the elements from last to first: 5 4 3 2 1. Don't create a second array — just loop in reverse.

Hint: start your counter at the last index and count down.

Loop for (int i = nums.length - 1; i >= 0; i--) and print nums[i] each time. Start at length - 1 (the last index) and stop at 0.

Task 2 — Above Average
For int[] marks = {70, 85, 90, 60, 95};, first work out the average, then count how many marks are above that average and print the count.

This needs two passes: one loop to add everything up for the average (remember (double) the sum), then a second loop with if (marks[i] > average) count++;.

Task 3 — Largest and Where
For int[] data = {42, 17, 89, 5, 63};, find the largest value and the index it lives at. Print both, like Largest 89 at index 2.

Track two variables: max and maxIndex. When you find a bigger value at index i, update both — max = data[i]; and maxIndex = i;.

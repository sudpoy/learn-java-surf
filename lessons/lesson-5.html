Methods

Stop repeating yourself. A method is a named, reusable block of code you can run whenever you need it — give it inputs, get a result back. Learn to declare, call, pass parameters, return values, and even reuse one name for several jobs.

Lecture: ~40 min
Exercise: ~15 min
Topics: declare · call · parameters · return · scope · overloading
Part 1 — What Is a Method & Why Use One

Imagine the buttons on a microwave. You press "Popcorn" and a whole sequence of steps runs — you don't re-program it every time. A method is exactly that: you write a block of code once, give it a name, and then "press the button" (call it) whenever you want it to run.

The big reason is DRY — Don't Repeat Yourself. If you copy-paste the same lines in five places and later find a bug, you have to fix it five times. Put it in a method, and you fix it once. Methods also give messy code structure, like chapters in a book.

Write Once, Call Many Times

Here greet is defined once but called three times. Notice the program always starts in main, then jumps to a method when it's called and comes back afterward:

public class Main {

    // A method: a named, reusable block of code
    static void greet() {
        System.out.println("Hello there!");
        System.out.println("Welcome to Java.");
    }

    public static void main(String[] args) {
        greet();              // "press the button"...
        greet();              // ...as many times as you like
        System.out.println("----");
        greet();
    }
}
💡 Execution always begins in main

Java runs main first. When it reaches greet(), it pauses, runs every line inside greet, then returns to exactly where it left off and continues. A method does nothing until it is called.

Part 2 — Anatomy of a Method

Every method declaration has the same four pieces. Here's static int square(int n) taken apart:

PartExampleWhat it means
ModifierstaticLets you call it directly, without building an object first
Return typeintThe kind of value handed back (void means nothing is returned)
NamesquareWhat you type to call it — pick a clear, verb-like name
Parameters(int n)The inputs it needs, each with a type, inside parentheses
⚠️ Why static for now

For this lesson, every method is static. That keyword means the method belongs to the program itself, so main (which is also static) can call it directly. In Lesson 7 you'll meet non-static methods that belong to individual objects — but one step at a time.

Part 3 — Parameters & Arguments

A method becomes far more useful when you can feed it different inputs. A parameter is the placeholder named in the method's parentheses; the argument is the actual value you hand over when you call it. Same idea, two names — depending on which side you're looking from.

public class Main {

    // 'name' is the PARAMETER — a placeholder for whatever is passed in
    static void greetUser(String name) {
        System.out.println("Hello, " + name + "!");
    }

    public static void main(String[] args) {
        greetUser("Mia");     // "Mia" is the ARGUMENT we pass in
        greetUser("Leo");
        greetUser("Ava");
    }
}
💡 Parameter vs argument

Easy way to keep them straight: the parameter is what the method expects (written when you define it); the argument is what you actually give it (written when you call it). The argument's type must match the parameter's type.

Part 4 — Return Values vs void

So far our methods just did something (printed text) and returned nothing — that's what void means. But often you want a method to compute an answer and hand it back so you can use it. That's a return value, and the return type goes where void used to be.

public class Main {

    // Returns an int instead of printing it
    static int square(int n) {
        return n * n;          // hand the answer back to the caller
    }

    public static void main(String[] args) {
        int result = square(5);                 // capture the value in a variable
        System.out.println("5 squared is " + result);
        System.out.println("9 squared is " + square(9));   // or use it directly
    }
}
⚠️ return ends the method immediately

As soon as a return runs, the method stops and jumps back to the caller — any code after it on that path won't run. A method declared with a return type (like int) must return a value of that type on every path.

Returning a true/false Answer

Methods can return any type — including boolean. A method that answers a yes/no question reads beautifully inside an if:

public class Main {

    static boolean isEven(int n) {
        return n % 2 == 0;     // true when n divides evenly by 2
    }

    public static void main(String[] args) {
        int[] nums = {7, 10, 13, 4};
        for (int n : nums) {
            if (isEven(n)) {
                System.out.println(n + " is even");
            } else {
                System.out.println(n + " is odd");
            }
        }
    }
}
Part 5 — Multiple Parameters

A method can take several inputs — just separate the parameters with commas. The order matters: the first argument fills the first parameter, the second fills the second, and so on.

public class Main {

    static int rectangleArea(int width, int height) {
        return width * height;
    }

    static String fullName(String first, String last) {
        return first + " " + last;
    }

    public static void main(String[] args) {
        int area = rectangleArea(4, 6);          // width = 4, height = 6
        System.out.println("Area: " + area);
        System.out.println("Name: " + fullName("Ada", "Lovelace"));
    }
}
💡 Order and type must line up

If a method expects (int width, int height), you must pass two ints in that order. Calling rectangleArea(4, 6) sets width to 4 and height to 6 — swap them and you'd get a different rectangle. Java also checks the types match.

Part 6 — Scope of Local Variables

A variable created inside a method is local to it — it's born when the method starts and disappears when it ends. Code outside can't see it. Also, when you pass a number to a method, Java hands over a copy of the value, so changing the parameter inside doesn't touch the original back in main.

public class Main {

    static void tryToChange(int x) {
        x = 999;                 // changes only this method's own copy
        int secret = 42;         // 'secret' exists only inside this method
        System.out.println("Inside the method:  x = " + x + ", secret = " + secret);
    }

    public static void main(String[] args) {
        int score = 10;
        tryToChange(score);
        System.out.println("Back in main:        score = " + score);  // still 10!
        // System.out.println(secret); // ERROR: 'secret' does not exist out here
    }
}
⚠️ Each method has its own world

The x inside tryToChange and the score in main are completely separate variables, even though one was copied from the other. This is why methods are safe to reuse — they can't accidentally trample variables elsewhere in your program.

Part 7 — A Gentle Intro to Overloading

Java lets you give several methods the same name, as long as their parameter lists differ (different number or types of parameters). This is called overloading. Java figures out which one you meant by looking at the arguments you pass.

public class Main {

    static int add(int a, int b) {
        return a + b;
    }
    static int add(int a, int b, int c) {     // same name, three parameters
        return a + b + c;
    }
    static double add(double a, double b) {   // same name, double parameters
        return a + b;
    }

    public static void main(String[] args) {
        System.out.println(add(2, 3));         // picks the two-int version
        System.out.println(add(2, 3, 4));      // picks the three-int version
        System.out.println(add(2.5, 1.5));     // picks the double version
    }
}
💡 You already use overloading

System.out.println is overloaded! There's a version for ints, one for Strings, one for doubles, and more — that's why you can print almost anything with the same method name. Overloading keeps related jobs under one easy-to-remember name.

Exercise — 15 Minutes
⌨️ Coding Challenge ⏱ ~15 min

Task 1 — cube()
Write a method static int cube(int n) that returns n * n * n. Call it from main for 2, 3, and 4, and print each result (you should get 8, 27, 64).

Hint: the return type is int, so the method body just needs one return line.

Define static int cube(int n) { return n * n * n; } next to main. Then in main: System.out.println(cube(2)); and so on.

Task 2 — max3()
Write static int max3(int a, int b, int c) that returns the largest of three numbers. Test it with max3(4, 9, 2) → 9 and max3(7, 1, 7) → 7.

Start by assuming a is the biggest: int biggest = a;. Then if (b > biggest) biggest = b; and the same for c. Finally return biggest;.

Task 3 — printStars()
Write a void method static void printStars(int n) that prints a line of n star characters, then call it with 3, 5, and 1. (Combines methods with the loops you learned in Lesson 3.)

Inside the method, loop for (int i = 0; i < n; i++) System.out.print("*"); then System.out.println(); to end the line. It's void because it prints rather than returning.
